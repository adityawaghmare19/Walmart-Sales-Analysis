# Walmart-Sales-Analysis-SQL
This project focuses on analyzing Walmart sales transactions to identify business patterns, customer purchasing behavior, and product performance. By exploring sales data from multiple Walmart branches, the analysis provides insights that can help improve business decisions, optimize sales strategies, and understand customer preferences.

The dataset used for this project is sourced from the Kaggle Walmart Sales Forecasting Competition, which contains historical sales records from Walmart stores. The competition challenges participants to forecast department-wise sales while considering factors such as holiday markdown events that may influence purchasing behavior.

Project Objectives

The primary objectives of this project are:

Analyze sales performance across different Walmart branches.
Identify the best and least performing product categories.
Study monthly and daily sales trends.
Understand customer demographics and purchasing habits.
Compare branch performance using revenue, profit, and ratings.
Generate business insights that can support better decision-making.

3. Feature Engineering

To enrich the dataset and make analysis easier, additional columns were generated.

Time of Day

A new column called time_of_day was created to classify transactions into:

Morning
Afternoon
Evening

This helps determine when customers shop the most.

Day Name

A new column called day_name was generated from the transaction date.

This allows us to identify:

Busiest weekdays
Branch-wise weekly trends
Month Name

A new column called month_name was extracted from the purchase date.

This enables monthly comparisons for:

Revenue
Profit
Customer activity

Expected Outcomes

This project provides valuable business insights into Walmart's sales operations by identifying customer purchasing patterns, high-performing product categories, branch performance, and sales trends.
